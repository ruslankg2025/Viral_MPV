# VIRAL_MPV — Viral Monitor для контент-мейкеров

## Назначение

Viral Monitor — SaaS-платформа для контент-команд, SMM-агентств и частных креаторов, закрывает полный цикл работы с коротким видео:
- мониторинг вирусных роликов в YouTube, Instagram, TikTok, VK
- AI-разбор паттернов
- генерация сценариев под профиль аккаунта
- (фаза 2) автоматическая сборка видео с AI-аватаром и публикация

Решает три боли: ручной ресёрч + продакшн съедают 20+ часов в неделю; контент без привязки к нише даёт низкий отклик; сборка и публикация требуют монтажёра + SMM. Бизнес-кейс — заменить связку «аналитик + копирайтер + видеомонтажёр + SMM» одним инструментом по подписке.

## Roadmap

### MVP (текущая фаза)
По ТЗ MVP-модули: `shell`, `profile`, `monitor` (A2), `processor` (A3), `script` (A5). Реально подключены также `downloader` (A1) и `knowledge` (этап 4 self-learning).
- Без auth-модуля, до 10 аккаунтов на установку, переключение через UI-свитчер
- 14 кураторских ниш из мокапа VIRA Dashboard
- 4 preset тонов (Экспертный / Разговорный / Энергичный / Спокойный)
- Объединённый экран Профиль + Настройки

### Фаза 2 (полный SaaS)
- Multi-tenant PostgreSQL (schema-per-tenant для Business, RLS для Free/Pro)
- Auth: OAuth 2.0 + email/password, TOTP 2FA, ролевая модель
- BYOK с шифрованием AES-256-GCM, мастер-ключ в HashiCorp Vault
- Полная таксономия (~200 ниш)
- Выделенный `api-gateway` модуль (когда ≥3 модулей с проводкой)
- AI Studio (talking head, TTS, b-roll, рендер)
- Автопубликация YouTube / Instagram / TikTok / VK
- Календарь публикаций, трекинг собственных аккаунтов
- Биллинг (Stripe + ЮKassa), локальная LLM на GPU

### Ближайшие задачи
- Mode 5 «Загрузка авторского MP4» — multipart upload, thumbnail, опц. deep_analyze
- Подключение ИИ-ключей (OpenAI как первый)
