# Mode 5 — Загрузка авторского MP4

**Дата старта:** 2026-05-07
**Статус:** черновик (детали будут уточнены при старте работы)
**Цель:** добавить в UI пятый режим — загрузка собственного MP4 пользователем; обогащение thumbnail и метаданными; опциональный deep_analyze через processor.

## Контекст

Существующие режимы работают через мониторинг чужих видео (через Apify). Mode 5 — отдельный путь для собственного контента: пользователь грузит файл локально, система делает то же самое, что и для внешнего ролика, но без поиска.

Связанные модули:
- `Modules/shell/` — endpoint приёма multipart upload, маршрутизация в downloader/processor
- `Modules/downloader/` — приёмник файла (или прямой uplink в processor — уточнить)
- `Modules/processor/` — обработка, transcript, thumbnail
- `Modules/shell/static/app/` — фронт (новая кнопка / форма / drag-and-drop)
